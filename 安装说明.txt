================================================================================
电力交易员刷题 — 本地使用说明（打包版 / 源码运行）
================================================================================

【一、使用已打包好的程序（推荐）】

1. 解压收到的 zip，得到文件夹「电力交易员刷题」。
2. 将题库 Excel 文件放到该文件夹内：
   - 中级工：电力交易员中级工题库2025(2).xlsx
   - 二级/三级样卷：banks/erji.xlsx、banks/sanji.xlsx、banks/papers.json（打包版会一并复制）
   打开网页后可在首页切换题库。
   刷题模式：
   - 开始本轮刷题：随机 100 单选 + 30 多选 + 40 判断（错题优先）
   - 错题集重刷：只做错题本里的题
   - 按样卷顺序：先选题库，再选具体套卷（如 样卷2-三级-第1套），按原卷顺序整套做完；中级工题库为按全库题号顺序
3. 双击运行（必须在「dist」文件夹里，不要用「build」）：
   - 正确：…/刷题软件/dist/电力交易员刷题/电力交易员刷题
   - 错误：…/刷题软件/build/… 下的同名文件（仅为打包中间产物，会报 Python3 找不到）
   - Windows：dist\电力交易员刷题\电力交易员刷题.exe
   - macOS：dist/电力交易员刷题/电力交易员刷题
4. 若未自动打开浏览器，请手动访问：http://127.0.0.1:5001/
5. 关闭程序：关闭弹出的黑色命令行窗口，或在窗口里按 Ctrl+C。
6. 学习进度保存在同目录下的 question_progress.csv，勿删以免丢失进度。

macOS 若提示「无法打开」：可在「系统设置 - 隐私与安全性」中允许，或右键 - 打开。

【网页打不开时】

1. 确认黑色命令行窗口还开着（关掉窗口即停止服务）。
2. 地址必须是 http://127.0.0.1:5001/ （默认端口为 5001，不是 5000）。请从地址栏核对，不要沿用旧书签里的 5000。
3. 若终端提示「端口已被占用，已改用 5xxx」，请用终端里打印的新端口号访问。
4. 先访问 http://127.0.0.1:5001/health 若能看到 {"ok":true} 说明服务正常，再打开首页。
5. 不要重复运行多份程序，否则会抢端口；关掉多余的窗口再试。

【三、在线网页版（GitHub Pages，可选）】

桌面打包与本地 python web_app.py 的方式不变。若要把同一题库发布成公开网页（使用
https://<你的用户名>.github.io/<仓库名>/ 这类地址）：

1. 在电脑上安装 Python 与依赖（pip install flask pandas openpyxl 等，与本地刷题相同）。
2. 项目根目录执行：  python3 export_bank_for_pages.py
   会在 docs/ 写入 banks.json 与各题库 questions_*.json。
3. 用 Git 初始化仓库，将项目（含 docs/）推送到 GitHub。
4. 打开仓库 Settings → Pages → Build and deployment：
   Source 选「Deploy from a branch」，Branch 选 main（或你的默认分支），文件夹选「/docs」保存。
5. 等待几分钟后用浏览器访问站点。更新题库后需重新执行 export 并推送 docs/ 下的 JSON。

说明：GitHub Pages 纯静态页默认把进度存在访客浏览器，换设备或清缓存会丢失，也无法多端同步。
多端同步请使用同一账号登录已部署的 Flask/Render 网站（不要只用 Pages）。
若要把 Pages 接到 Render：在 docs/config.js 填写 SHUATI_API_BASE 为你的 Render 地址（不要猜、不要写密码）；
同时在 Render 环境变量 CORS_ORIGINS 填 Pages 的 origin（例如 https://yourname.github.io）。
更新题库后需重新执行 export 并推送 docs/ 下的 JSON。

【四、Render 后端（Flask）】

GitHub 仓库是 https://github.com/AimePython/shuati ，代码已推送；Render 控制台里需要你自己新建一次服务（仓库不会自动出现）。

一键导入 Blueprint（登录 Render 后打开）：
  https://render.com/deploy?repo=https://github.com/AimePython/shuati

或在 Dashboard 手动创建：
  1. 打开 https://dashboard.render.com
  2. New → Blueprint，连接 GitHub 账号（若尚未授权）
  3. 选择仓库 AimePython/shuati，Deploy Blueprint
  也可 New → Web Service → 选同一仓库：
     Build：pip install -r requirements.txt
     Start：gunicorn web_app:app --bind 0.0.0.0:$PORT --workers 1 --threads 8

账号与做题进度默认写在应用目录（user_progress 下的 CSV）。免费实例磁盘是临时的，重启会丢。
若要长期保留并多端同步，请在 Render 加一块持久磁盘，并把环境变量 DATA_DIR 指到挂载路径（例如 /data）。
免费套餐通常不能挂磁盘；不要在 render.yaml 里写 disk，以免 Blueprint 部署失败。代码会读取 DATA_DIR。
已有账号会自动视为「已通过」，不受影响。

关页是否保存：在服务端网页答题后立刻关标签，再换浏览器（或清 cookie 后）用同一账号登录，已做题与错题本应仍在。
